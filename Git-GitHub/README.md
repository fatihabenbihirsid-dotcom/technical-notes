# 🔀 Git & GitHub

Bienvenue dans mon cours **Git & GitHub**.

Ce cours présente les principales notions nécessaires pour utiliser Git, gérer les versions d'un projet et travailler avec GitHub.

---

## 📚 Cours complet

### 📄 Support de cours

**[📥 Ouvrir le cours complet Git & GitHub — PDF](./Cours_complet_Git_et_GitHub.pdf)**

Le document contient les explications, commandes, exemples pratiques et erreurs fréquentes rencontrées lors de l'utilisation de Git et GitHub.

## 📖 Contenu du cours

### 🔹 Git

* Qu'est-ce que Git ?
* Installation et configuration
* Création d'un dépôt
* `git init`
* `git status`
* `git add`
* `git commit`
* `git log`
* `git diff`

### 🔹 GitHub

* Création d'un repository
* Connexion entre Git et GitHub
* `git remote`
* `git push`
* `git pull`
* `git fetch`
* Synchronisation avec GitHub

### 🔹 Branches

* Création d'une branche
* Changement de branche
* Fusion
* Suppression d'une branche

### 🔹 Conflits

* Comprendre les conflits
* Résoudre un conflit
* `git merge --abort`
* Conflits dans `.gitignore`
* `--allow-unrelated-histories`

### 🔹 Erreurs fréquentes

* `fetch first`
* `non-fast-forward`
* `remote origin already exists`
* `repository not found`
* `MERGE_HEAD exists`
* Problèmes de synchronisation

---

## 🛠️ Commandes essentielles

```bash
git init
git status
git add .
git commit -m "message"
git log
git branch
git switch
git remote -v
git pull
git push
```

---

## 🎯 Objectif

À la fin de ce cours, vous devez être capable de :

* gérer l'historique d'un projet avec Git ;
* créer et gérer des commits ;
* travailler avec des branches ;
* connecter un projet à GitHub ;
* envoyer et récupérer des modifications ;
* comprendre et résoudre les conflits ;
* diagnostiquer les erreurs Git courantes.
